# プッシュ通知 実機確認チェックリスト（手動テスト）

自動テストで検証できないのは **実機端末までの通知到達** だけです
（配信呼び出し・ペイロード内容・購読管理・TTL は `test/worker/push.test.ts`
および `test/worker/push-payload.test.ts` で自動検証済み。設計 §10-2 / FR-6）。
このファイルは残り 1 項目を手動で確認し、結果を記録するためのもの。

要件: FR-6.1〜FR-6.5 / 受け入れ基準 8（`docs/requirements.md` §10）
設計: `docs/design.md` §6.5（プッシュ）・§8（Service Worker）

---

## 0. 前提（1 回だけ）

- [ ] VAPID 鍵を生成してデプロイする（**ローカル dev では実配信されない**）

  ```bash
  npx web-push generate-vapid-keys --json
  npx wrangler secret put VAPID_PUBLIC_KEY
  npx wrangler secret put VAPID_PRIVATE_KEY
  npx wrangler secret put VAPID_SUBJECT     # mailto:you@example.com
  npx wrangler deploy
  ```

- [ ] 本番 URL（HTTPS）にアクセスできること。`http://localhost` では Push API が
  使えないため **実機確認はデプロイ後**（ Workers.dev ドメインで可）。
- [ ] ルームを作成し、**別の端末**から招待リンク + PIN で参加する
  （同一端末の別タブでも可だが、端末を分けた方が到達確認として確実）。
- [ ] 確認中はブラウザの通知設定を「許可」にする（拒否状態だと通知は出ないが、
  ポーリング受話は動く）。

## 1. 到達・内容の確認（端末ごとに実施）

| # | 確認こと | 期待結果 | 根拠 |
|---|----------|----------|------|
| 1 | 参加時に通知を許可する | 許可後、相手からの送信で通知が届く。D1 の `push_subs` に自分の購読が 1 行増える | FR-6.1 |
| 2 | 相手がテキストを送る | **5 秒程度**で通知が出る。タイトル = 差出人の表示名、本文 = メッセージ本文 | FR-6.2 |
| 3 | 相手が画像を送る | タイトル = 差出人、本文 = 「📷 画像メッセージが届きました」 | FR-6.3 |
| 4 | 自分自身が送信する | 自分の送信では通知が **出ない** | FR-6.4 / 設計 §6.5 |
| 5 | 通知の文面を確認する | PIN・ルーム鍵・ルーム ID・復号前の文字列が一切表示されない | NFR-8 / 制約 2 |
| 6 | 通知をタップする | 該当ルームのタブがあればフォーカス、無ければ `/ルームID` を新規表示してチャットが開く | FR-6.5 |
| 7 | 通知を閉じたあとアプリを開く | チャット本文はポーリングで追いついており、二重表示もない | FR-3.6 / FR-4.1 |
| 8 | 通知を拒否した端末 | 通知は来ない。ただしページを開いていれば通常どおり受話できる | FR-6.1（任意機能） |
| 9 | 端末を機内モードにしてから 1 時間後に復帰 | 古いメッセージの通知は再表示されない（TTL 3600 秒で破棄）。復帰後のチャットは最新まで追いつく | 設計 §6.5（`TTL: 3600`） |
| 10 | 7 日以上放置したルームを再度開く | サーバ側は消えているが、ローカル IndexedDB の閲覧は継続できる | FR-8.1 / 受け入れ基準 6・7 |

## 2. 購読まわりの確認（任意・D1 が見られる人向け）

```bash
npx wrangler d1 execute tempchat --remote --json \
  --command "SELECT room_id, COUNT(*) FROM push_subs GROUP BY room_id"
```

- [ ] 1 ルーム 21 端末分を購読すると、最も古い購読が消えて **20 件以内**に保たれる（FR-6.6）
- [ ] 通知設定から通知をオフにすると `push_subs` の行が減る（A8 の DELETE）
- [ ] 配信で 404/410 が返った購読が消える（実測は難しいので自動テストで担保済み）
